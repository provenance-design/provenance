# Provenance Archive

A curated archive of 1,000 canonical design objects — product, furniture, graphic, lighting, architecture, textile, ceramic, glass, metalwork — connected through argued relationships.

**[provenancearchive.uk](https://provenancearchive.uk)**

## What It Is

Provenance is a network of design objects where the connection — not the object — is the primary unit of design knowledge. Every connection between two objects makes a specific, argued claim about their relationship: a shared material carrying different meaning, a designed disagreement, a method that transfers across contexts.

The archive is built as a teaching resource for design students and as the foundation of a developing scholarly research practice in design education.

## Six Connection Types

| Type | What It Argues |
|---|---|
| **Argument** | A designed disagreement — opposing criteria applied to the same territory |
| **Lineage** | Transfer across time — a logic that reappears in a later solution |
| **Material Thread** | Shared material carrying different meaning across contexts |
| **Same Problem** | The same brief answered differently |
| **Zeitgeist** | Parallel answers within the same cultural moment |
| **Shared Method** | Transferable process producing different outcomes |

## Technical

Built with Next.js 14 and React 18. Hosted on Vercel. Data lives in JavaScript files — no database.
